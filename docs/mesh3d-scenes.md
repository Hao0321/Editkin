# Editable mesh scenes: experimental source

**Visual disposition: ART_REJECTED.** The current sphere-video, heavy extruded-type and hard-frame recipes were explicitly rejected by the creator. The retained twelve-second output is failure evidence. Technical geometry/command/render checks do not permit packaging these recipes as polished defaults.

`EditProject.scene3d` carries `editkin.mesh-scene/v1`. Ordinary
`set_mesh_3d_scene` commands validate, enter history, save and reopen the same
scene. Omitting `scene` removes it. Existing project schema version stays at 8;
older runtimes that do not expose the mesh tools are **not** safe editors for
these projects: they may discard an unknown field. Check the actual runtime.

The source MCP exposes `list_mesh_3d_templates` with `DESIGN_REWORK` and an
empty template list. `prepare_mesh_3d_template` rejects the three withdrawn
IDs before reading the input project. The editor's creation controls are also
withdrawn; existing scenes remain editable and the research compiler is retained.
Do not recreate a rejected design through handwritten equivalent commands.
Once a newly designed template is restored and verified, bind its exact ordinary
commands to the existing Video Autopilot v4 plan and material/design evidence.
Preparation is not an audit, application, render or visual approval.
The source treatment classifier recognizes mesh vfx, motion, title and camera
families; this does not certify a real audited automated film.

Existing manual scenes retain their editing controls. Text, thickness, depth,
source clip, material colors, camera field of view, ambient light and grid are
editable. Cameras and objects have bounded poses and keyframes. The physical
geometry includes boxes, spheres, toruses, cylindrical video patches and
extruded glyphs with bevels and holes. Templates use Editkin blue/white with a
subordinate stationary grid; palettes and reference assets are not copied.

Preview and formal export share `shared-cpu-triangle-zbuffer/v1`, a CPU triangle
executor with frustum clipping, perspective-correct UVs and per-pixel depth.
The existing native GPU **plane** compositor explicitly rejects mesh scenes.
Formal export decodes owned SDR sources into bounded texture pipes, renders
the mesh base and rejoins the existing caption, Motion and voice/music path.
The portrait delivery sample is 540 × 960 at 30 fps, rendered at 1.5× resolution
before downsampling; preview has a 320-pixel short edge. These are independent
resolutions, not a promise of real-time full-resolution playback.

Current limits are opaque Rec.709 textures, ambient/directional vertex light,
32 objects, 60,000 triangles and six textures. Source clips must cover their
whole scene range. Unbound visible clips, nested mesh compositions, simultaneous
plane/particle/tracking scenes, unmaterialized filters/masks/clip animation and
HDR/ACES inputs fail validation. Texture alpha blending, PBR, shadow maps,
native GPU meshes and a general Blender-style studio are not implemented.
Normalize legitimate HLG footage to verified SDR first; preserve source hashes
and conversion evidence.

Extruded text uses actual Noto Sans TC 700/900 TTF contours. The source desktop
bridges read only those two known bundled faces, with bounded no-follow reads,
manifest v2 byte/SHA verification and directory containment. No arbitrary font
filename, external URL or CSP widening is introduced. The Rust command source
still requires native compilation and actual packaged IPC validation. The
browser development route loads the same faces locally. Noto Sans TC uses
OFL-1.1; retain its license and physical-face provenance. `three` 0.186.1 and
`opentype.js` 1.3.4 provide licensed MIT math/geometry/font infrastructure;
the application owns its renderer, templates, UI and scene contract.

Before promoting a candidate, verify the same runtime's ordinary edits/undo,
save/reopen, continuous playback, source replacement and full decoded export.
Inspect title fit, glyph edges, UV seams, depth ownership, reading holds and
source relevance against the supplied references. A clean decode, geometry test
or source benchmark is not installation, full-film quality or reference parity.
