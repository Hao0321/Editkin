# Agent 剪輯計畫起稿

狀態：**單一無音軌片段的起稿到輸出已接通；一般影片仍未完成**（2026-09-29）。

## 為何做這一層

區網 Qwen 在三個隔離回合中，能查詢 Kit 收據與工具，卻未從空白 run 寫出可用的 `plan.v4.json`。另一次曾把空 transform patch 當作剪輯命令；新版 parser 已拒絕。固定的來源雜湊、收據與設計 metadata 應由 Editkin 從已驗證 Kit run 組裝；Agent 應負責內容判斷。

## 已完成

- `get_kit_plan_context` 驗證 Kit run、專案綁定與收據 SHA-256，回傳來源、素材語意綁定、專案摘要、路由證據、已存草稿狀態和設計工具呼叫方式。路由推薦不等於模型實際身分。
- `draft_kit_single_clip_plan` 接收短字幕、主題、proof beat、畫面主體和觀眾描述。它只支援**一個明確 visual-only、24–3600 影格、最多 60 秒的來源片段**。它讀取 Kit 證據、Editkin 設計 brief 與美學系統，產生一段 proof beat、可編輯字幕及完整 v4 草稿。無音軌來源使用空音訊層；推論來源標成未核實，不冒稱 Qwen 或 Codex。草稿用排他建立寫入，避免覆蓋既有檔案。
- 起稿工具只寫 `plan.v4.json`。使用者要求完成影片時，`finish_kit_single_clip_edit` 在同一 Agent 程序依序呼叫**原 Kit** plan、audit、apply、render；只接受單字幕、空音軌的有效 v4 草稿，拒絕不明來源和重複執行，停止於 `human-review`。正式 parser 拒絕空 patch；Kit 封存前仍重新解析。
- 用新版可攜 EXE 內附 gateway 在隔離 4 秒 FFmpeg 合成素材驗證：起稿 → Kit plan → audit → apply → render；輸出 4 秒可解碼影片、保留 1 段可編輯字幕，來源 SHA-256 未變。這份字幕文字由測試腳本提供，**不是 Qwen 自主寫出的剪輯意圖**。
- 區網 Qwen 在 OpenCode 原生 session 的第二回合確實呼叫起稿工具，成功寫出可解析的草稿。第一回合把 gateway 工具誤認為一般 Editkin 工具，於是補上 OpenCode 實際工具名稱和側欄指引。測試提示仍明確給出字幕與節拍，不能視為 Qwen 自主看懂素材或完成編劇。
- 新一輪隔離測試用接近剪輯台實際送出的上下文與自然語句。Qwen 自行讀證據、決定合成素材的字幕措辭、起稿；在「完成輸出」請求下又核對草稿並呼叫完成工具。原 Kit 全部機器步驟完成，產出 4 秒可解碼 MP4 和 1 段可編輯字幕，原片未變。測試素材的語意收據仍由工程腳本提交；真人尚未審片，不能據此宣稱真實素材的畫面理解、節奏或故事品質。

## 下一個施工切面

擴充為多片段、多 beat 的 Agent 意圖：每段須有來源證據、時間範圍、畫面／音訊命令與設計決策；Editkin 負責結構組裝與交叉驗證。拒絕未證實對白、錯誤來源、空操作、工作區外路徑與沒有可見／可聽改變的計畫。以真實素材實測模型自主挑選段落、節奏、字幕、音訊及對畫面的理解，再做真人審片。合成 fixture 的技術通過不代表故事或美感通過。
